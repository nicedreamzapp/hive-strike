# Music

Every bed in the game is one of Matt's own Song Forge instrumentals, pulled from
his library and normalised to -22 LUFS. Nothing was generated for the game.

Don't like one? `SWAP=B5=<id> python3 tools/assign_beds.py` then rebuild.
